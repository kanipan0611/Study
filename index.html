学習アプリ 弱点特化ドリル

出題設定

分野タグごとの正答率を集計し、正答率が低いタグほど出やすい重み付けで出題します（すべて端末内で計算・API不使用）。

問題がありません。「問題管理」または「AI補充」から問題を登録してください。

弱点ダッシュボード

1問ずつ登録

JSONでまとめて登録

形式を見る 
[
  {
    "subject": "宅建",
    "tag": "権利関係",
    "question": "問題文",
    "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
    "answerIndex": 0,
    "explanation": "解説（任意）"
  }
]

answerIndex は 0 始まり（最初の選択肢が正解なら 0）。

登録済みの問題

AIで問題を補充する

特定タグの問題が足りないときだけ使う任意機能です。日々の出題・採点はAIを一切使いません。

方法1：プロンプトをコピーして無料で作る 無料

下のボタンでプロンプトをコピーし、普段使っているAIチャット（Claude・ChatGPTなど）に貼り付けてください。返ってきたJSONを下の欄に貼れば取り込めます。API課金は発生しません。

方法2：APIキーでワンボタン生成 課金対象

⚠️ この操作だけがAPI課金の対象です（Anthropic APIの従量課金）。ボタンを押した時だけ通信し、結果は端末に保存されます。
