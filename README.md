# 学習アプリ（弱点特化ドリル）

科目を問わず使える四択問題ドリル。`index.html` をブラウザで開くだけで動きます（サーバー・ビルド不要）。

## 基本方針

- **日々の学習（出題・採点・弱点分析）はすべて端末内のローカル計算で完結**し、API課金は一切発生しない
- AIは「問題の補充」だけに使う任意機能。課金対象の操作は明確に分離してある

## 使い方

**スマホ・PC共通（推奨）**: GitHub Pages で公開されているURLを開く

> https://kanipan0611.github.io/Study/

スマホではブラウザのメニューから「**ホーム画面に追加**」すると、アプリのように起動でき、オフラインでも動作します（PWA対応。AI補充のAPI呼び出しのみ通信が必要）。

**PCローカルで使う場合**:

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 「問題管理」タブで問題を登録する（1問ずつ、またはJSONまとめ貼り付け）
3. 「出題」タブで科目を選んで開始 → 正答率が低い分野タグほど出やすい重み付けで出題される
4. 「ダッシュボード」タブで科目・タグ別の正答率を確認（弱い順に表示）

データ（問題・解答履歴）はブラウザの localStorage に永続保存され、閉じても消えません。
「問題管理」タブの**バックアップ書き出し/読み込み**で、機種変更やブラウザ変更にも対応できます。

## データの型（科目非依存）

```json
{
  "subject": "宅建",
  "tag": "権利関係",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answerIndex": 0,
  "explanation": "解説（任意）"
}
```

科目もタグも自由文字列なので、宅建・簿記・TOEICなど何にでも同じ仕組みで使えます。

## 出題エンジン（ローカル計算・API不使用）

- タグ別正答率を Laplace 平滑化（`(正解+1)/(解答+2)`）で算出
- タグの重み = `(1 − 正答率) + 0.15` で重み付け抽選 → タグ内の問題も同じ式で弱いものを優先
- 未学習タグは正答率50%相当として中程度に出題される（新しい分野が埋もれない）

## AI補充（2ルート）

| 方法 | 費用 | 手順 |
|---|---|---|
| **方法1: プロンプトコピー** | 無料 | 生成用プロンプトをコピー → 普段のAIチャット（Claude / ChatGPT等）に貼る → 返ってきたJSONを貼り戻す |
| **方法2: APIキー** | 課金対象 | Anthropic APIキーを入力してワンボタン生成（`claude-opus-4-8` を使用、構造化出力でJSONを保証） |

方法1なら**API課金ゼロ**で運用できます。方法2はボタンを押したときだけ通信し、画面に「課金対象」と明示しています。APIキーは端末の localStorage にのみ保存されます。

## 注意

- localStorage はブラウザ・端末ごとに独立です。別端末で使う場合はバックアップJSONで移してください
- ブラウザの「サイトデータ削除」を行うとデータが消えるので、定期的なバックアップ書き出しを推奨します
